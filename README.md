# 知序 · AI 学习工作台

面向计算机学生的长期实践项目。第一门课程从《数据结构与算法》开始，围绕课程资料、带出处的问答、练习与复习逐步搭建完整学习流程。

## 当前状态：v0.1 结构原型

已实现五个入口：学习总览、课程资料、学习问答、练习复习、开发路线图。

- 课程笔记可新增、编辑、搜索、删除，支持导入 TXT / Markdown。
- 三组预置问答可以打开实际对应的自写示例原文。
- 三道固定练习支持提交答案、查看解释和错题记录。
- 笔记、问题、答题和个人计划勾选存储在当前浏览器，可导出 JSON。
- 开发路线图包含阶段交付物、前置依赖、验收标准和架构说明。

**真实 AI、云端数据库、用户登录和跨设备同步尚未接入。** 自由问题只记录，不自动生成答案；新增笔记不参与预置问答。当前本地问答适配器不会发送任何模型请求。

## 本地运行

需要支持 ES 模块的现代 Node.js；项目没有第三方运行依赖。

```sh
npm start
```

浏览器打开 http://127.0.0.1:4173 。请通过 HTTP 服务访问，不要直接双击 index.html。

```sh
npm run check
```

校验 JavaScript 语法、来源引用、未知问题的诚实回退、固定题数据、资料操作、本地计划记录及文档完整性。

## 源码结构

```text
dist/
  index.html          应用外壳
  styles.css          视觉样式与响应式布局
  favicon.svg         网站图标
  js/
    app.js            路由、表单、交互
    views.js          页面组件
    data.js           原创课程样例与阶段计划
    store.js          本地 Repository
    demo-provider.js  显式预置问答适配器
    ui.js             通用组件、安全文本输出与导出
  docs/
    project-plan.md   完整开发计划
    architecture.md   数据与服务架构
scripts/
  serve.mjs           本地静态服务
  check.mjs           核心数据与交互逻辑校验
```

## 持续开发路线

00 当前原型 → 01 真实问答 → 02 可靠检索 → 03 学习闭环 → 04 按需求选择实战或研究方向。

先稳定资料 ID、引用与答题记录，再通过服务端接口替换模型、检索和存储实现。模型密钥始终保留在服务端。Python / PyTorch 研究模块独立运行，通过 HTTP 接入 Sites 服务层。

详见 [项目计划](dist/docs/project-plan.md) 与 [架构设计](dist/docs/architecture.md)。

## 数据说明

示例笔记与题目为本项目自写内容。浏览器本地记录不会自动上传；更换浏览器或清除网站数据会影响记录，请按需导出留存。JSON 导出包含个人笔记与学习记录，分享前可自行查看内容。
